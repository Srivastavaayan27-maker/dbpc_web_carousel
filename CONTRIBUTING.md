# Contributing to DBPC Carousel

First off, thank you for considering contributing to this project! Your help and support are what make open-source projects thrive.

## How Can You Contribute?

### 1. Reporting Issues
- Found a bug? Please [open an issue](https://github.com/Srivastavaayan27-maker/dbpc_web_carousel/issues) with a clear description of the problem.
- Include steps to reproduce the issue and any relevant screenshots.
- Check existing issues first to avoid duplicates.

### 2. Suggesting Features
- Have a great idea? [Submit a feature request](https://github.com/Srivastavaayan27-maker/dbpc_web_carousel/issues).
- Clearly explain the feature, its benefits, and how it would improve the project.

### 3. Improving Documentation
- Found something unclear? Help improve the documentation.
- Fix typos, update examples, or improve explanations.

---

## Guidelines

### Code of Conduct
Please adhere to the project's [Code of Conduct](CODE_OF_CONDUCT.md) to create a welcoming environment.

### Commit Messages
- Write meaningful and descriptive commit messages.
- Use present tense (e.g., "Add feature" not "Added feature").
- Include references to issues where relevant.

### Coding Standards
- Follow the coding style and conventions of the project.
- Use meaningful variable and function names.
- Avoid introducing unnecessary dependencies.

### Pull Request Checklist
- Ensure all tests pass.
- Include clear and concise documentation for your changes.
- Reference the issue your pull request is addressing (if applicable).
- Be responsive to feedback and open to revisions.
