# Don Bosco Park Circus Website Carousel Element

This carousel, used for making the Don Bosco Park Circus Website is a simple implementation of a carousel similar to the one found on the Johns Hopkins University homepage. It uses HTML, CSS (SCSS), and JavaScript to create a sliding carousel with captions.

## Project Structure

In this repo, you shall find the following file structure - 

css/styles.css

images/dbpcfield

images/dbpcinner

images/outer

js/script.js

scss/styles.scss

index.html

readme.md

### CSS

The CSS files contain the styling of the webpage. This file is linked to the index.html file. The original stylesheet is in the SASS folder.
